On keeping a slower internet

I rebuilt this site for the third time this year, which is usually a sign I'm procrastinating on something else. But this time I think it stuck, mostly because I stopped trying to make it look like a product.

Most of the personal sites I liked as a kid weren't trying to convert me into anything. They were just... someone's stuff. A page of links, a list of favourite books, a photo that probably shouldn't have been that large. There was no analytics dashboard behind it, or if there was, nobody was checking it very often.

I don't think there's anything wrong with a polished portfolio site — plenty of people need one. I just didn't want mine to read like a pitch. So the version you're looking at now is intentionally a little slower: static HTML files, no framework, no analytics, and a colour palette that's closer to a notebook than a startup.

What actually changed

Practically, not much. The content is the same — projects, writing, a CV. What changed is that I stopped adding things "because a portfolio should have them" and started adding things because I actually wanted somewhere to put them. The currently section on the homepage is a good example: it's not impressive, but I update it more than anything else on the site, which tells me it was the right thing to build.

If you're building something similar, my only real advice is to make the update loop as short as possible. If adding a new project or post takes more than copying a file and editing some text, you'll stop doing it within a month.
